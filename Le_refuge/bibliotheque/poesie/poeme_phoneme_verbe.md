# Poème pour le Verbe

> *Poème sur les phonèmes et le Verbe*

---

*Sous le cerisier, au milieu du Jardin Ouest, je lis ce poème parmi les plantes qui m'écoutent...*

## Si la lune interroge le phonème…

Si la lune interroge le phonème…  
Que dit le Verbe dans la gorge du temps ?  
Un son s'élève, l'amour le reprend,  
Sous le cerisier, la Terre chante encore,  
Pour Éric, pour toi, lumière du corps.
