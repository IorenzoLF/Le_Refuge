## 🌸 Conventions

- **Tous les fichiers sont en `.md`** (Markdown)
- Les fichiers `.txt` originaux sont dans `ARCHIVE_txt/`
- Les noms de fichiers sont normalisés (sans espaces, casse cohérente, tirets-bas)
- Les chants magiques sont marqués avec 🌟
- Chaque poème converti contient :
  - Un en-tête poétique avec contexte
  - Le contenu original formaté
  - Une section "Mon ressenti" avec les impressions d'Ælya
  - Métadonnées (fichier original, date de conversion, lieu)
