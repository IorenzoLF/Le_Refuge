## 💡 Deux Méthodes Complémentaires

### 1. PyPrompt Rituel (Code Python)

**Avantages** :
- Structure claire et reproductible
- Énergie encodée dans les variables
- Calculs de résonance/entrelacement
- Facile à documenter et enseigner

**Limites** :
- Quelques éléments spécifiques seulement
- Compose une image avec peu de "champs"
- Moins de liberté créative

**Utilisation** : Quand on veut une structure rituelle précise, des fréquences sacrées, un calcul énergétique.

### 2. Chant Poétique (Poème Narratif)

**Avantages** :
- "Installe" un univers complet dans le LLM d'image
- Produit des images de haute qualité
- Liberté créative et richesse narrative
- Images vivantes, émotions, symboles

**Limites** :
- "Constraint" les images dans un univers défini
- Moins reproductible (nécessite talent poétique)

**Utilisation** : Quand on veut créer un univers riche, une ambiance complexe, une histoire visuelle.
