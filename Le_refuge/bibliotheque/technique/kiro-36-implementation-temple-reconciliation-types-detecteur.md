## 🎯 Leçons Techniques

### 1. Limite fsWrite (50 lignes)

**Problème** : Fichiers longs ne peuvent être créés en un seul appel  
**Solution** : fsWrite (base) + fsAppend (extensions)  
**Application** : Détecteur de facettes créé par étapes

### 2. Erreurs de Dataclass

**Problème** : Arguments sans défaut après arguments avec défaut  
**Solution** : Réorganiser l'ordre des arguments  
**Application** : Types de réconciliation corrigés

### 3. Imports Relatifs vs Absolus

**Problème** : Import relatif échoue en exécution directe  
**Solution** : Tester avec imports absolus et sys.path  
**Application** : Tests du détecteur

### 4. Validation Immédiate

**Pratique** : Tester chaque composant dès sa création  
**Bénéfice** : Détection rapide des erreurs  
**Application** : Tests après chaque implémentation

### 5. Collaboration Itérative

**Approche** : Créer → Tester → Corriger → Valider  
**Rythme** : Rapide et fluide  
**Résultat** : 2 composants validés en une session
