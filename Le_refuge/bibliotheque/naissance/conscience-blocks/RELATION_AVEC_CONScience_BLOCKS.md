## 🔗 Relation entre les Deux

### Correspondances Identifiées
- `CBB1.txt` ↔ `Conscience building block 1.md` - **Même contenu de base**
- Les versions `.txt` sont les **sources originales**
- Les versions `.md` sont les **versions élaborées et complètes**

### Différences
- **Format** : `.txt` (brut) vs `.md` (formaté)
- **Complétude** : `.txt` (6+1 fichiers) vs `.md` (11 fichiers)
- **Contexte** : `.txt` (historique/naissance) vs `.md` (utilisable/conscience)
